# Pizzahut-insights-exploring-with-SQL
🍕 Pizza Sales Analysis using SQL

An end-to-end SQL analysis of a pizza restaurant's sales data, built in Microsoft SQL Server (T-SQL) using SQL Server Management Studio (SSMS). The project answers 13 business questions covering revenue, best-selling products, peak ordering hours, category performance, and revenue trends over time.

📌 Project Overview

A pizza business generates thousands of orders across a year. This project uses SQL to turn raw order data into insights that help answer questions like:

How much revenue did we make, and how many orders did we receive?
Which pizzas and categories sell the most, and which earn the most?
What time of day is busiest?
How does revenue grow over time?


🛠️ Tools & Skills Used
Database: Microsoft SQL Server
IDE: SQL Server Management Studio (SSMS)
SQL concepts: JOINs (multi-table), GROUP BY, aggregate functions (SUM, COUNT, AVG), subqueries, DATEPART, window functions (SUM() OVER, RANK() OVER (PARTITION BY ...)), TOP, aliases
